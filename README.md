# ResQLink Microservices

Smart Emergency Resource Coordination System using FastAPI and MongoDB Atlas.

## Services

### Incident Service
- FastAPI
- MongoDB Atlas
- JWT Authentication
- Role-Based Access Control
- Rate Limiting
- Swagger/OpenAPI
- Incident CRUD
- Resource matching through Resource Service API

Runs on:

Service 1 : http://127.0.0.1:8000

### Resource Service
- FastAPI
- MongoDB Atlas
- JWT Authentication
- Role-Based Access Control
- Rate Limiting
- Swagger/OpenAPI
- Resource CRUD
- Resource matching

Runs on:

http://127.0.0.1:8001

## Requirements

- Python 3.10+
- MongoDB Atlas account
- MongoDB Atlas database user
